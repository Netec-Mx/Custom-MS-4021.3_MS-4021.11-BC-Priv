# Experiencia de inmersión en Copilot: Gerentes de Negocios & Ventas



## Plataforma de laboratorios



Te damos la bienvenida a la **plataforma de laboratorios** del curso **Experiencia de inmersión en Copilot: Gerentes de Negocios & Ventas**. Aquí podrás explorar diferentes tecnologías a través de prácticas guiadas. ¡Desarrolla tus habilidades y lleva tus conocimientos al siguiente nivel!



## Lista de laboratorios



Cada uno de estos laboratorios está diseñado para ofrecerte una experiencia práctica. Haz clic en los enlaces para comenzar.



### [Demostración 1. Preparar el contexto comercial desde Outlook](Capitulo01) 

  - **Descripción**: Se desarrolla la capacidad de organizar y priorizar correos clave relacionados con el entorno comercial, utilizando Copilot en Outlook para sintetizar información relevante (riesgos, oportunidades y acciones). Además, se construye un contexto estructurado que facilita el análisis posterior en herramientas como Excel y Microsoft 365 Copilot Chat

  - ⏱️ **Duración estimada**: 25 min.



### [Demostración 2. Analizar resultados comerciales en Excel y diseñar iniciativas con Microsoft 365 Copilot Chat](Capitulo02)

  - **Descripción**: Se enfoca en el análisis de resultados comerciales mediante el uso de Copilot en Excel para identificar patrones, brechas y áreas de mejora. A partir de estos hallazgos, se aprovecha Microsoft 365 Copilot Chat para generar recomendaciones estratégicas e iniciativas personalizadas que impulsen el desempeño comercial.

  - ⏱️ **Duración estimada**: 35 min.



### [Demostración 3. Crear una presentación ejecutiva con Copilot en PowerPoint](Capitulo03)

  - **Descripción**: Se utiliza Copilot en PowerPoint para transformar hallazgos comerciales en una presentación ejecutiva clara y estructurada. Se afinan diapositivas con indicadores y oportunidades clave, y se construye una narrativa estratégica dirigida a la toma de decisiones por parte de líderes comerciales.

  - ⏱️**Duración estimada**: 25 min.
